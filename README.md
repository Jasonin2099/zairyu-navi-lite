# zairyu-navi-lite · 在留手続きナビ Lite

A tiny static (HTML/CSS/JS, no backend, no tracking) guide to two common residence procedures in Japan:
**在留期間更新許可申請 (Extension of period of stay)** and **資格外活動許可 (Permission to engage in activity other than that permitted)**.
Enter your card's expiry date and it shows when you can apply, plus links to the official pages.

## 日本語
在留カードの期限を入力すると、在留期間更新の申請可能日（3か月前から）と期限、資格外活動許可の要点を表示する軽量な静的サイトです。データは `data.js` にあり、すべて出入国在留管理庁の公開情報に基づき出典を付けています。

## 中文
输入在留卡到期日，即可看到在留期间更新的可申请日（提前3个月）和截止日，以及资格外活动许可（打工）的要点。纯静态，无后台，不收集任何数据。所有内容均附出入国在留管理厅官方出处。

## Usage
Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).
