# Contributing

Thanks for helping! This project only states facts that can be traced to an official page.

1. Every procedure in `data.js` must have `src` URLs under `https://www.moj.go.jp/isa/`.
2. Provide `name`, `summary`, `notes`, `docs` in all of `ja`, `zh`, `en` (same number of items).
3. Do not add personal data, tracking, analytics, or a backend.
4. Run `npm test` before opening a pull request.
5. If official rules change, update the "checked" date in `app.js` and `README.md`.

This tool is not legal advice; keep wording neutral and point users to the official pages.
